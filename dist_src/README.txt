Avernum 6 日本語化パッチ __VERSION__
========================================

Spiderweb Software の RPG「Avernum 6」（Steam 版）を日本語で遊べるようにする非公式パッチです。
会話・本・クエスト・アイテム名・画面の文字・看板・地図など、ゲーム内のほぼすべての文章を日本語にします。

紹介ページ: __PAGE_URL__


■ 対応しているゲーム
  Steam 版 Avernum 6（アプリ番号 206060）に対応しています。
  GOG 版・Humble 版など他のストアの版でも動くように作ってありますが、動作は未確認です。
  対応できない版では日本語化を自動で止め、英語のまま普通に起動します。
  他のストアの版で試した方は、動いたかどうかを avernum_jp\avernum_jp.log を添えて GitHub の Issues でお知らせください。


■ インストール
  ZIP の中身（dsound.dll、avernum_jp.ini、avernum_jp フォルダ）を、ゲームのフォルダ
  （Avernum 6.exe があるフォルダ）にそのままコピーするだけです。
  ゲームのフォルダは、Steam でゲームを右クリック →「管理」→「ローカルファイルを閲覧」で開けます。

  あとは Steam からゲームを起動してください。
  （起動時に出る画面の大きさを選ぶ小さな窓は、Windows の標準の画面なので英語のままです。）
  初回の起動時に、お手元のゲームのファイルから日本語版のデータを作り、avernum_jp\cache フォルダに保存します。
  ゲームの元のファイルは書き換えません。

  このパッチには元のゲームのファイルは入っていません（日本語版との差分だけが入っています）。


■ アンインストール（元に戻す）
  ゲームのフォルダから dsound.dll、avernum_jp.ini、avernum_jp フォルダを削除します。


■ 設定
  avernum_jp.ini で、日本語の文字のフォント・太さ・大きさ・上下の位置と、行の間隔を変えられます
  （既定は MS UI Gothic の太字。英数字はゲームの元のフォントのまま表示します）。


■ うまく動かないとき
  ・英語のままの場合: avernum_jp\avernum_jp.log を開き、「not translated」と出ていないか確認してください。
    ゲームのファイルが元と違う（更新された、別のMODで変更されている）と、そのファイルは英語のままになります。
    Steam の「ゲームファイルの整合性を確認」を実行すると直ることがあります。
  ・英語のまま起動する場合は、avernum_jp\avernum_jp.log に「not supported」と出ていないか確認してください。
    お使いの Avernum 6.exe に対応できなかったことを示します（ゲームの更新や、他のストアの版など）。


■ 注意
  ・英語版で作ったセーブデータを読み込むと、セーブに記録済みの文字（メモやログなど）は英語のまま表示されることがあります。
    新しく始めるのがおすすめです。
  ・誤訳や不自然な箇所、表示の崩れがあれば GitHub の Issues でお知らせください。
  ・ベータ版です。誤訳や表示の崩れが残っていることがあります。
